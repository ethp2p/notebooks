# Plan 01: foundation (Bun + Vite + React + Tailwind + shadcn)

> **For agentic workers:** REQUIRED SUB-SKILL: use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.
>

>
> **IF YOU DEVIATE from this plan at any point** (renamed file, different dependency, different signature, swapped task order, adopted a convention the plan did not specify), append to `ERRATA.md` BEFORE marking the step complete. Format is in `ERRATA.md`.

**Goal:** Replace the current Astro site with a Vite + React + TypeScript app on Bun, wired with Tailwind and the full shadcn/ui primitive set, themed to the tokens in `.impeccable.md`. Landing, archive placeholder, and about pages load on the new stack. Test harness and CI run on Bun.

**Architecture:** Single-page React app served by a thin index.html (no SSG; two static pages are inlined as components). Vite builds to `site/dist/`. Tailwind reads from `site/tailwind.config.ts`. CSS variables in `site/src/styles/tokens.css` expose the palette; Tailwind colors map to them. shadcn components come from the CLI and are placed under `site/src/components/ui/`. The existing Astro site in `site/` is deleted wholesale: nothing in the new site depends on legacy files.

**Tech Stack:** Bun ≥ 1.1, Vite 7+, React 19, React Router 7, TypeScript 5.6 strict, Tailwind CSS 3.4, shadcn/ui CLI, Vitest (Bun-test compatible), Playwright.
