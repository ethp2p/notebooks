Delay is the time between block inclusion (slot_start) and when the transaction was first seen in the mempool — applicable only to transactions with visibility "after".
A large delay means the transaction was included but the network only observed it in the mempool well after the block was proposed, which is consistent with out-of-band (private) submission followed by delayed re-broadcast.
Log-scale y-axis is used because delays also span several orders of magnitude.
