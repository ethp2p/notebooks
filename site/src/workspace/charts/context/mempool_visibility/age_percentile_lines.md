Age is the time a transaction spent in the mempool before it was included in a block (mempool_seen_at to slot_start). Only transactions with visibility "before" have a meaningful age value.
Higher percentile lines (p95, p99) reflect long-tail waiting times, which can indicate congestion, low-priority transactions, or transactions submitted speculatively well before a target block.
Log-scale y-axis is used because ages span several orders of magnitude.
