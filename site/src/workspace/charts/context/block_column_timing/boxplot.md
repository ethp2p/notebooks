Boxplot of per-slot spread between block arrival and last column seen, grouped by blob count bucket (0-5, 6+) and MEV vs local block.
Higher blob counts require more data columns to propagate, so the spread is expected to grow with blob count; this chart makes that relationship visible.
The MEV vs local split reveals whether commercially optimised blocks follow a different propagation pattern from locally built blocks at the same blob count.
Box: 25th-75th percentile. Line: median. Whiskers: min/max excluding outliers.
